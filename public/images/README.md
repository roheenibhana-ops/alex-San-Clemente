# Image slots

Drop photos in the matching folder and add one line to `lib/images.ts`.

| Key | Folder | Where it appears |
| --- | --- | --- |
| `hood:<slug>` | `neighborhoods/` | Neighborhood cards, home tabs, and the hero of each neighborhood page |
| `guide:<slug>` | `lifestyle/` | Lifestyle guide cards (beaches, parks-trails, food-drink, local-tips) |
| `post:<slug>` | `blog/` | Blog cards and the hero image on each post |
| `food:<slug>` | `food/` | Food roundup cards (coffee, brunch, dinner, seafood-sunset) |

Specs: landscape, 2400px wide or more, JPG. Compress before use, and write descriptive alt text.
