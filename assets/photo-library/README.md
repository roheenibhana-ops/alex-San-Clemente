# Photo library

Originals we have been given, kept here so they can be reused in blog posts, guides and neighborhood pages.
This folder is NOT served on the site. To use a photo, resize it (about 1800px wide, JPG, quality ~82),
put it under `public/images/<neighborhoods|lifestyle|blog|food>/`, and add an entry in `lib/images.ts`.
Alt text must describe what is visible. Do not name a place unless we are sure of it.
